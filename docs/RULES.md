# 玩法说明

中文 · [English](RULES.en.md)

选手编号在本轮固定，不是名次。随机签位决定相遇顺序；除精选排名外，其他玩法只产生赛事冠军，不保证全局偏好排序。

- **精选排名**：按胜者树逐个提取前 K 名，移除已入选的胜者后重新比较受影响的路径。准确排序需要你的偏好前后一致、可传递。只有一张图时直接入选。
- **一败退场**：单败淘汰，轮空自动晋级。未被否决时 N 张图需要 N−1 次比较。
- **连胜擂台**：固定随机挑战队列；每场胜者留台，败者退场，最后的擂主获胜。连胜数只统计实际赢下的比较。
- **双败复活**：首败进入复活区，第二败退场。总决赛若复活区选手击败仍未输过的选手，再进行一次重置决赛。
- **小组出线**：按人数均分为 2 的幂次个小组，每组通常 3–6 张。组内两两比较，胜一场得一分；先比总分，再比同分选手的相互成绩。仍影响前两名顺序或出线时，进行有限加赛。各组前二跨组淘汰；进入淘汰阶段后小组成绩锁定。

## 裁判与撤销

一票否决取消图片的本轮资格；同时否决两张算一个动作。`Ctrl+Z` 撤销最近一次投票或否决，恢复相关名次与赛程。

精选排名会从剩余图片补选，数量不足时按实际人数结束。其他赛制不会复活已正常淘汰的选手；冠军被否决可能留下空缺。所有图片都被否决时正常结束为零入选，不强凑冠军。

小组阶段的否决会移除相关有效积分并重新判断出线；进入淘汰阶段后不重算已锁定的组分。自动轮空与否决不计作赢下一场比赛。

返回准备区会保留否决标记，可手动“重新纳入”；再玩一轮只使用未被否决的图片。开始实际文件整理后，本轮比赛操作锁定，避免结果与文件去向不一致。
